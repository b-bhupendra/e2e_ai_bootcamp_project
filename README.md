## ⚙️ Quick Start

### 1. Clone & Navigate
If accessing directly:
```bash
git clone https://github.com/b-bhupendra/e2e_ai_bootcamp_project.git
cd e2e_ai_bootcamp_project
```

Or when navigating inside the `AI-Bootcamp-code-basics` hub:
```bash
cd projects/e2e_ai_bootcamp_project
```

### 2. Set Up Virtual Environment
```bash
# Create virtual environment
python -m venv .venv

# Activate environment
# On Windows:
.venv\Scripts\activate
# On Linux/macOS:
source .venv/bin/activate
```

### 3. Install Dependencies
```bash
pip install -r requirements.txt
```

### 4. Configure Environment
```bash
cp .env.example .env
# Edit .env with your specific API keys or configuration
```

### 5. Run the Application
```bash
python main.py
```
